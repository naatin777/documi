# 用語集

Documi のドキュメントや UI、MCP で使われる用語を定義する。

## Artifact

Documi が管理する文書の単位。`goal` / `requirement` / `architecture` / `design` / `decision` / `contract` / `verification` / `guide` の 8 種類がある。1 つの Artifact は 1 つの明確な関心事を扱う。

## Artifact Type

Artifact の分類。frontmatter の `type` フィールドと、格納ディレクトリ（`goals/` など）で表す。

## ID

Artifact を一意に識別する 5 桁の数字。ファイル名の先頭から導出され、Type との組み合わせ（例: `requirement:00001`）で Artifact を参照する。

## Relation

Artifact 間の参照関係。frontmatter の `relations` に外向き参照として記述し、逆参照（Incoming Relations）は読み込み時に算出する。

## Frontmatter

Markdown / MDX ファイル先頭の YAML ブロック。`type` / `title` / `description` / `status` などのメタデータを保持する。

## Status

Artifact の承認状態。`draft`（草案）/ `accepted`（承認済み）/ `deprecated`（廃止済み）の 3 種類。実装・検証の状態とは独立している。
