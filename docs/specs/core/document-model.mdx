# ドキュメントモデル・MDX 安全解析・グラフ・鮮度履歴仕様

## ファイル構造と識別

<Spec id="core.document-model" stability="stable" derives="goals/ai-reproducibility">
  **When** Documi が `docs/` ディレクトリを読み込むとき、
  **the** Document Core **shall** 任意階層の `.mdx` / `.md` ファイルを連番なしで再帰走査し、拡張子を除いた POSIX 相対パスをドキュメント ID として割り当てるとともに、任意の `date`（`YYYY-MM-DD` / `YYYY-MM`）メタデータを解析して `decision` 文書を新しい決定日順に整列する。
</Spec>

<Spec id="core.type-inference" stability="stable" derives="goals/low-friction-governance">
  **When** ドキュメントの frontmatter に `type` が省略されたとき、
  **the** Document Core **shall** 最上位ディレクトリ名 → ファイル名の順に 9 種類の Artifact Type を自動推論し、判別できない場合は警告を記録しつつ `guide` として読み込む。
</Spec>

## セマンティックブロックと安全解析

<Spec id="core.mdx-blocks" stability="stable" derives="goals/ai-reproducibility">
  **When** MDX 本文に `<Spec>` / `<Constraint>` / `<Outcome>` / `<Note>` / `<TermDef>` が記述されているとき、
  **the** Document Core **shall** mdast からブロック構造と正規化 SHA-256 `contentHash` を抽出し、プロジェクト全体でのブロック ID 重複を検出する。
</Spec>

<Spec id="core.mdx-safety" stability="stable" derives="goals/low-friction-governance">
  **If** MDX 本文に ESM import/export・JSX 式 `{...}`・スプレッド属性・未許可コンポーネントが含まれる場合、
  **then the** Document Core **shall** コードを実行せず `mdx-unsupported` 問題として報告する。
</Spec>

## Rooted DAG と脱線防止

<Spec id="core.rooted-dag" stability="stable" derives="goals/low-friction-governance">
  **When** `intent="normative"` の `<Spec>`（または `<Spec>` を持たない `spec` 文書）が存在するとき、
  **the** Document Core **shall** `derives` 辺を辿って 1 つ以上の `goal` に到達できることを検証し、到達できない場合は `orphan-spec` として報告する。`intent="idea"` のブロックは対象外とする。
</Spec>

<Spec id="core.auto-mentions" stability="stable" derives="goals/human-comprehension">
  **When** 本文中に他ドキュメントへの相対 Markdown リンクまたは `<Term>` 参照が存在するとき、
  **the** Document Core **shall** `mentions` エッジを自動構築し、参照先と逆参照 (`incoming`) の双方に反映する。
</Spec>

## ドキュメント鮮度・最新変更箇所・過去版参照

<Spec id="core.doc-history" stability="evolving" derives="goals/human-comprehension">
  **When** Document Core が `docs/` を読み込むか、指定ドキュメントの履歴・過去バージョンを要求されたとき、
  **the** Document Core **shall** 読み取り専用の Git 連携（非 Git 環境ではファイル時刻へのフォールバック）により各文書の作成日時・最終更新日時・未コミット変更状態・コミット履歴・最新変更の本文基準行レンジを算出し、検証済みのコミット SHA に対して過去バージョンの文書本文を安全に返却する。Git リポジトリへの書き込み操作は一切行わない。
</Spec>
