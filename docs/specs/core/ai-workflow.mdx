# プロジェクト設定・Agent Skills・AI CLI・MCP 精密編集仕様

## プロジェクト設定ファイルと双方向パス解決

<Spec id="core.project-config" stability="evolving" derives="goals/low-friction-governance">
  **When** CLI・HTTP サーバー・MCP サーバーが `projectRoot` と `docsDir` を解決するとき、
  **the** Document Core **shall** 既定を `<projectRoot>/docs` としつつプロジェクトルート直下の設定ファイル（`.documi.json` / `.documi.yml` / `.documi.yaml` / `documi.json`）から `docs` と `testReport` を自動読み込みし、`--project` のみ指定時は `<projectRoot>/<docs>` を、`--docs` のみ指定時はその親ディレクトリを `projectRoot` として双方向に自動解決する。不正な構文や未定義キーは `ConfigError` として拒否する。
</Spec>

## Agent Skills 配布と Brownfield 導入初期化

<Spec id="core.agent-skills-init" stability="evolving" derives="goals/ai-reproducibility">
  **When** `documi init` が実行されたとき、
  **the** Document Core および CLI **shall** 既存の `AGENTS.md` 等と競合させずに標準 Agent Skills 形式（既定 `<projectRoot>/.agents/skills/`）で CLI ベースの日常運用スキル（`documi/SKILL.md`）・既存コードベース導入スキル（`documi-bootstrap/SKILL.md`）・対話型仕様レビュー／認識合わせクイズスキル（`documi-review/SKILL.md`）と `docs/` 雛形を指定言語（`--en` / `--ja` / `--lang`、既定 `en`）で冪等に生成する。既存ファイルは明示フラグ（`--force-skills`）なしに上書きしない。
</Spec>

## AI・人間向け CLI クエリ・精密編集と MCP 自己完結

<Spec id="core.ai-cli" stability="evolving" derives="goals/ai-reproducibility">
  **When** AI エージェントまたは人間が CLI 経由でプロジェクトマップ・文書検索・Spec 文脈取得・ブロック精密編集を実行するとき、あるいは MCP クライアントが `documi mcp` / `/mcp` に接続するとき、
  **the** Documi CLI および MCP Server **shall** 共通の Document Core を介して CLI 経路（`map` / `list` / `show` / `relations` / `search` / `query` / `context` / `block` / `term` / `scaffold`、`--json` 対応）と MCP 経路（`McpServer` の `instructions` 内蔵）の双方を互いに依存せず自己完結して提供する。
</Spec>

## コンテキスト最小化のための MCP 精密編集

<Spec id="core.mcp-surgical-edit" stability="evolving" derives="goals/ai-reproducibility">
  **When** AI エージェントが MCP 経由で特定のセマンティックブロック・用語・新規文書雛形・ブロック ID リネームを操作するとき、
  **the** Document Core および MCP Server **shall** 読み取りツールで各ブロックの正確な `docPath`・`startLine`・`endLine` を提供するとともに、対象ブロックや対象ファイルのみを AST 位置ベースで安全に書き換えて即時再読込と検証結果を返す。`docs/` 外への脱出、MDX 危険構文（式・ESM・未許可コンポーネント）、ID 重複、および `docs/.documi/reviews.json` への書き込みは一切拒否する。
</Spec>
