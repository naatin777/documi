# Traceability Matrix 廃止・Figma 風グラフ操作・Code Explorer 3 ペイン化の採用

<Outcome id="dec.graph-and-code-ux" stability="stable">
  2D の Traceability Matrix（表形式マトリクス）は廃止し、依存構造の俯瞰は **フルビューポートの Sigma.js 力学ネットワークグラフ（`/graph`）＋右サイドプレビュー** へ一本化する。グラフ操作は **Figma 風トラックパッド規約（2 本指スワイプ＝パン、ピンチまたは `⌘`/`Ctrl`＋ホイール＝カーソル中心ズーム）** を採用する。Code Explorer（`/code`）は **左ファイルツリー（開閉可）・中央 Shiki コード・右インスペクタ（`Symbols` 公開シンボル一覧 / `Links` 逆リンク、伸縮・開閉可）** の 3 ペイン構成とする。
</Outcome>

## 背景と検討した代替案

### 1. Traceability Matrix（`/graph` 内タブ・`/api/matrix`）の廃止
- **棄却した現状案**: 行×列の 2D テーブルで全ドキュメント間の参照を表示する案。ドキュメント数が増えるにつれて縦横スクロールが破綻し、グラフ＋右サイドプレビューや `documi check` のカバレッジ集計で上位互換に代替できた。
- **採用**: UI・API・Core・静的サイト出力から Matrix を完全削除し、`/graph` を純粋なフルビューポートグラフ体験に集中させた。

### 2. グラフのトラックパッド／マウス操作（Figma 風 vs 従来マップ風）
- **棄却案（ホイール＝常にズーム）**: ノート PC のトラックパッドで 2 本指スワイプすると意図せず急拡大／縮小してしまい、グラフ内を落ち着いて移動できなかった。
- **採用**: 2 本指スワイプは慣性感のあるスムーズなパン、トラックパッドのピンチ操作（`ctrlKey` 付き wheel）および `⌘`/`Ctrl`＋ホイールをカーソル位置中心のズームに統一した。

### 3. Code Explorer の公開シンボル・逆リンク配置
- **棄却案（コード上部に縦積み）**: 公開シンボル一覧や関連 Spec をコード本文の上に積むと、肝心のソースコードが画面下に押しやられ、ファイルツリーも常時固定で狭い画面で窮屈だった。
- **採用**: 左のファイルツリーを折りたたみ可能にし、右側に伸縮・折りたたみ可能なインスペクタ（`Symbols` タブ＝AST 抽出公開シンボルジャンプ、`Links` タブ＝逆リンク Spec / Doc / Term）を配置した。

## 影響・見直し条件

- **プラス面**: `/graph` と `/code` の閲覧領域が広がり、ノート PC トラックパッドでも直感的に操作できる。Matrix 関連の重複コード・API も削減できた。
- **見直し条件**: 規制対応・監査提出などの用途で「全 Spec × 全 Test の一覧表」を静的に出力したい要件が出た場合は、インタラクティブ UI ではなく `documi export` / CLI レポート出力として別途検討する。
