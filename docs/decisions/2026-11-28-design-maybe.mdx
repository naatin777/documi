# AI が仮に決めた箇所を、仮決定だと分かる形で残すか

<Decision id="dec.design-maybe" summary="仮決定に印を付けて残す" stability="evolving">
  問い: AI が仮に決めた箇所を、仮決定だと分かる形で残すか

決定: 仮決定に印を付けて残す を選んだ。
得るもの: 速さと透明さを両立できる。失うもの: 印の確認漏れがあると、見えるだけで解決しない。

判断材料: 全部人間に聞くと遅く、黙って埋めるとズレる。中間層があるかどうかで記録モデル全体が変わる。放っておくと、AI は「仮決定に印を付けて残す」で仮置きして進める。たとえば、エラーメッセージの文言や内部命名など、AI が仮に決めた箇所が後から「勝手に決められた」と感じる原因になる。印があれば、確定ではなく仮の決定だと分かる。
</Decision>
