# 技術選定: Bun + TypeScript + Hono

## 決定

- Runtime / Package Manager: **Bun**
- Language: **TypeScript**
- Backend: **Hono**
- Frontend: **React** + **Vite**

## 理由

- Bun は TypeScript をそのまま実行でき、単一コマンドでの開発・テスト・ビルドが可能
- Hono は Web 標準の Request/Response に準拠し、Bun・Node・Edge など実行環境に依存しない
- React + Vite は成熟したエコシステムで、HMR による快適な開発体験を提供する

## 検討した代替案

- Node.js + Express/Fastify: 実績はあるが、Bun の開発体験と比べて設定が増える
- 単一の SSR フレームワーク: 今回は閲覧専用のため、SPA + API の分離で十分と判断
