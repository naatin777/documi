# 気づきはこまめにメモし、その場で人間に聞くのは重要なものだけにするか

<Decision id="dec.capture-frequency" summary="メモは全部取り、話しかけるのは大事なものだけ" stability="evolving">
  問い: 気づきはこまめにメモし、その場で人間に聞くのは重要なものだけにするか

決定: メモは全部取り、話しかけるのは大事なものだけ を選んだ。
得るもの: 気づきを残しながら作業の流れを保てる。失うもの: 重要度判定を間違えると必要な確認が遅れる。

判断材料: 全部聞くと中断が増え、拾わないと蒸発する。この線引きは最初の UX 原則になる。放っておくと、AI は「メモは全部取り、話しかけるのは大事なものだけ」で仮置きして進める。たとえば、実装中に AI が「あれ、この命名おかしくない？」と気づいても、聞くほどでもないと判断するとその気づきは消える。逆に全部聞くと作業が止まる。
</Decision>
