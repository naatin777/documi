# Web UI・REST API・i18n の検証

## 1. 保証シナリオ（Given / When / Then）

### REST API 契約と非ローカル Origin 遮断

- **Given**: Hono REST API（`/api/overview`, `/api/tree`, `/api/documents/*`, `/api/graph`, `/api/terms`, `/api/reviews/*` 等）が起動している
- **When**: ローカル Origin から各エンドポイントを呼び出す、または外部サイトの `Origin` ヘッダ付きで `/api/*` へアクセスする
- **Then**: ローカル要求は Zod スキーマ通りの構造化 JSON（欠損時は 404/400）を返し、非ローカル Origin は読み書きとも 403 で拒否される

### Web ビューア・サイドバー・Review Queue・検索の動作

- **Given**: 複数の Artifact Type・`<TermDef>`・未承認 `<Spec>` を持つプロジェクトがロードされている
- **When**: Overview・Explorer（`Flow` / `Files`）・Document View・Review Queue・Graph・`Cmd+K` 検索を描画・操作する
- **Then**: 用語が自動リンクされ、Side-by-Side 差分プレビュー付きで承認操作ができ、SSE ライブ更新でファイル変更が即座に反映される

### 多言語カタログ（i18n）のキー・プレースホルダ完全一致

- **Given**: ベース言語（`en`）と翻訳ロケール（`ja`）の JSON カタログが存在する
- **When**: `tests/i18n.test.ts` で全キーと `{{placeholder}}` を比較し `setAppLocale` で切替える
- **Then**: 欠損キー・余剰キー・プレースホルダ不一致が 0 件であり、ロケール切替が安全に反映される
