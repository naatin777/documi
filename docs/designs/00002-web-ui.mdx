# Web UI の設計

## 画面構成

デスクトップではサイドバー + メイン領域の 2 ペイン構成とする。

- **サイドバー**: Glossary へのリンク、Artifact Type ごとの分類、文書一覧、読み込み問題の表示
- **メイン領域**: 選択した文書のメタデータ・本文・Relations を表示

## ルーティング

| パス | 画面 |
|---|---|
| `/` | `/glossary` へリダイレクト |
| `/glossary` | 用語集 |
| `/pages/:type/:id` | 個別ドキュメント |

`/pages/:type/:id` 形式は将来の SSG との互換性を考慮して採用する。

## データ取得

- `GET /api/documents` — サイドバーの一覧用（body を含まないサマリ）
- `GET /api/documents/:type/:id` — 文書詳細（body・relations・issues を含む）
- `GET /api/glossary` — 用語集
- `GET /api/status` — rootDir・問題一覧

## Markdown レンダリング

`react-markdown` + `remark-gfm` を使用する。`/pages/:type/:id` および `type:id` 形式のリンクは React Router の画面遷移に変換し、それ以外は外部リンクとして開く。
