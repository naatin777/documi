# Sigma.js グラフ可視化の設計

## 設計方針

数百ノード規模の仕様・設計・用語・ADR を有機的かつ直感的に探索できるよう、WebGL レンダラの **Sigma.js (v4)** と **Graphology** の上に、Obsidian Graph View と同じ **リアルタイム力学シミュレーション（Force-Directed Physics）** を実装する。

- **フルビューポート・円形展開**:
  - 初期配置を黄金角スパイラルで円形・星雲状に並べ、開いた瞬間に `requestAnimationFrame` ループで中心引力・ノード間反発力 (Coulomb)・エッジばね引力 (Hooke)・速度減衰を計算しながらリアルタイムに展開・収束させる
  - 固定ワールド境界 (`setCustomBBox`) + `autoRescale: 'once'` により、物理シミュレーション中もカメラがブレずにノードだけが滑らかに動く
- **弾性ドラッグとライブ物理調整**:
  - ノードをドラッグして引っ張ると、接続されているエッジがゴム紐のように作用して周囲のノードもリアルタイムに追従し、離した後は余韻を残して安定位置へ収束する（静止後は自動スリープして CPU 負荷ゼロ）
  - 右上の `⚙ Forces` パネルから Center force / Repel force / Link force / Link distance をリアルタイム調整でき、`⚡` ボタンで再シミュレーションできる
- **小さめドット＋下中央ラベルとリング・パルス強調**:
  - 通常時は全ノードを小さめの Type 色ドット＋下中央の短縮ラベル（`labelPosition: 'below'`・背景枠なし）で統一描画し、ノード同士の重なりを抑えてエッジの繋がりとクラスタ構造を見渡しやすくする
  - ホバー・選択時はテキストに箱や影を付けず、対象ノードと隣接ノードのドット外周をフラットな円形リング（`backdropArea: 'node'`）で囲み、接続エッジ上を向き（`from → to`）に沿って粒（フラット・影なし）が流れるオーバーレイアニメーションで関係方向を示す（未選択・未ホバー時はアニメーションループを停止）
- **2 種類の粒度とエッジ切替・右側即時プレビュー**:
  - `Documents`: 文書同士の関係を俯瞰（ノードサイズ＝接続次数に比例）
  - `Docs + Blocks`: 文書ノードの周りに `<Spec>` / `<Constraint>` / `<Outcome>` / `<TermDef>` が衛星のように展開
  - `All Links` / `Traceability Only` の切替、ホバー枠ハイライト、検索ボックスからのカメラフォーカス、ダブルクリックでのフルページ遷移
  - ノード未選択時はグラフを全幅表示し、ノードをクリックすると右側に `DocPeekPane` が開いて **グラフを離れずに該当文書・ブロックの本文と繋がりタブをその場で閲覧** できる
