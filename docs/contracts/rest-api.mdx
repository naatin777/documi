# REST API コントラクト

ローカルツール前提で同一オリジンおよび localhost 系 Origin からのみ許可される。
全エンドポイントは機能別 Hono サブルータ（`src/server/routes/`）と Zod バリデーション（`zValidator`）で構成され、Web UI クライアントは **Hono RPC (`hc<ApiRoutes>`)** 経由でサーバー定義から型を直接推論する（詳細は [Hono RPC + Zod 採用 ADR](../decisions/2026-11-hono-rpc-and-zod-api.mdx)）。

| Endpoint | 役割 |
|---|---|
| `GET /api/health` | ヘルスチェック (`{ ok: true }`) |
| `GET /api/overview` | 全体統計・Type 別件数・Review & Realization 内訳・要確認ブロック・未解決フィードバック・Goals・Outcomes・Orphan Specs |
| `GET /api/status` | `rootDir`, `loadedAt`, `documentCount`, `blockCount`, `issues` |
| `GET /api/tree` | 階層ツリー (`DocTreeNode[]`) と全ドキュメントサマリ |
| `GET /api/documents` | サマリ一覧 (`?type=` 絞り込み対応) |
| `GET /api/documents/*path` | 任意階層パス ID による単一ドキュメント詳細 (ブロック・エッジ・Realization・問題込み) |
| `GET /api/graph` | グラフノード＆エッジ一覧 (`?layers=trace\|all&granularity=docs\|blocks`) |
| `GET /api/matrix` | 全 `<Spec>` のトレーサビリティマトリクス |
| `GET /api/search` | ドキュメント＆セマンティックブロック横断検索 (`?q=&type=&limit=`) |
| `GET /api/terms` | 全 `<TermDef>` 用語定義一覧 |
| `GET /api/check` | AST シンボル検証を含む一括整合性チェック (`?strict=true`) |
| `GET /api/blocks` | レビュー対象セマンティックブロック一覧と Review 集計 (`/review` 受信箱用) |
| `GET /api/blocks/:id/diff` | 承認時点コミット (またはローカルキャッシュ) と現在本文の行 diff |
| `POST /api/blocks/:id/approve` | ブロックを承認し `docs/.documi/reviews.json` を更新 |
| `POST /api/blocks/:id/feedback` | AI 向けフィードバックコメントを追加 |
| `PATCH /api/blocks/:id/feedback/:feedbackId` | フィードバックの解決状態を切替 |
| `PATCH /api/blocks/:id/stability` | Stability 上書き設定 (`stable` / `evolving` / `volatile` / `null`) |
| `GET /api/events` | SSE ライブ更新ストリーム (`connected` / `reload` イベント) |
| `GET /api/source` | `<SourceRef>` 用の AST シンボル / 行範囲コード取得 |
| `GET /api/code/tree` | Code Explorer 用：`projectRoot` 配下のソースファイルツリーと各ファイルの紐づき `<Spec>` / `<SourceRef>` / `<TermDef>` 件数サマリ（`node_modules`・`.git`・`dist`・`docs/`・隠しディレクトリ除外） |
| `GET /api/code/file` | Code Explorer 用：POSIX 相対パス (`?path=src/...`) の読み取り専用ソース全文・言語・総行数・紐づき `<Spec>` / ドキュメント / `<TermDef>` 逆リンク一覧（`projectRoot` 外は `403`、未存在は `404`、バイナリ・サイズ上限超過は `400`） |
| `GET /api/icons/manifest` | Material Icon Theme のファイル・フォルダ名／拡張子マッピング（ライトテーマ上書き込み）を返す |
| `GET /api/icons/:name` | Material Icon Theme の SVG アイコン（allowlist 登録済みアイコン ID のみ配信・長期キャッシュ付き） |
| `GET /api/bundle` | 複数ドキュメントバンドル解決 (`?scope=all\|dir:...\|goal:...` または `?ids=...`) |
| `POST /api/export/pdf` | 単一文書の描画済み HTML から PDF 生成 |
| `POST /api/export/bundle-pdf` | ローカル `/bundle` URL を `Bun.WebView` で開いて複数文書 PDF 生成 |

## 共通エラー規約と副作用の範囲

- **エラーレスポンス形式**: エラー時は JSON `{ error: string }` を返し、用途別に以下の HTTP ステータスを用いる。
  - `400`: クエリ・JSON ボディの Zod バリデーション違反、不正なパラメータ
  - `403`: 許可されない Origin、または `projectRoot` 外参照・非ループバック URL などの境界違反
  - `404`: 指定されたドキュメント・ブロック・フィードバック・ソースファイル／シンボルが存在しない
  - `409`: 状態競合
  - `500` / `501`: サーバー内部エラー、または実行環境で未対応の PDF 出力機能
- **副作用の範囲**:
  - すべての `GET` エンドポイントは読み取り専用（副作用なし）。
  - 書き込み系エンドポイント（`POST /api/blocks/:id/approve`・`POST /api/blocks/:id/feedback`・`PATCH /api/blocks/:id/feedback/:feedbackId`・`PATCH /api/blocks/:id/stability`）の副作用は **`docs/.documi/reviews.json`（および `.documi/cache/`）の更新と SSE `reload` 配信に限定** され、MDX 本文は一切変更しない。
