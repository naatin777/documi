# REST API コントラクト

ローカルツール前提で同一オリジンおよび localhost 系 Origin からのみ許可される。
全エンドポイントは機能別 Hono サブルータ（`src/server/routes/`）と Zod バリデーション（`zValidator`）で構成され、Web UI クライアントは **Hono RPC (`hc<ApiRoutes>`)** 経由でサーバー定義から型を直接推論する（詳細は [Hono RPC + Zod 採用 ADR](../decisions/2026-11-hono-rpc-and-zod-api.mdx)）。

| Endpoint | 役割 |
|---|---|
| `GET /api/health` | ヘルスチェック (`{ ok: true }`) |
| `GET /api/overview` | 全体統計・Type 別件数・Review & Realization 内訳・ドキュメント健全性 (`health`)・要確認ブロック・Goals・Outcomes・Orphan Specs |
| `GET /api/status` | `rootDir`, `loadedAt`, `documentCount`, `blockCount`, `issues` |
| `GET /api/tree` | 階層ツリー (`DocTreeNode[]`) と全ドキュメントサマリ |
| `GET /api/documents` | サマリ一覧 (`?type=` 絞り込み対応) |
| `GET /api/documents/*path` | 任意階層パス ID による単一ドキュメント詳細 (ブロック・エッジ・Realization・鮮度・問題込み) |
| `GET /api/history` | 指定ドキュメント (`?id=&limit=`) の Git 鮮度・コミット履歴・最新変更の本文基準行レンジ一覧 |
| `GET /api/history/revision` | 指定ドキュメント (`?id=&commit=`) の過去コミット時点の本文・メタデータ（読み取り専用） |
| `GET /api/graph` | グラフノード＆エッジ一覧 (`?layers=trace\|all&granularity=docs\|blocks`) |
| `GET /api/search` | ドキュメント＆セマンティックブロック横断検索 (`?q=&type=&limit=&semantic=true\|false`、BM25＋用語展開または `rag.enabled` 時 RRF ハイブリッド) |
| `GET /api/terms` | 全 `<TermDef>` 用語定義一覧 |
| `GET /api/check` | AST シンボル検証・ドキュメント健全性 (`health`) を含む一括整合性チェック (`?strict=true&reviewGate=none\|stable\|all`) |
| `GET /api/blocks` | レビュー対象セマンティックブロック一覧（Git 変更分フラグ `changed`・承認メモ付き）と Review 集計 (`/review` 受信箱用) |
| `POST /api/blocks/approve-batch` | 指定した複数ブロック ID を確認メモ（任意 `note`）付きで一括承認し `docs/guard/reviews.json` を更新 |
| `GET /api/blocks/:id/diff` | 承認時点コミット (またはローカルキャッシュ) と現在本文の行 diff |
| `POST /api/blocks/:id/approve` | ブロックを承認し `docs/guard/reviews.json` を更新（任意 `author` / `note`） |
| `DELETE /api/blocks/:id/approve` | ブロックの承認を取り消し未承認 (`unreviewed`) へ戻す |
| `GET /api/events` | SSE ライブ更新ストリーム (`connected` / `reload` イベント) |
| `GET /api/source` | `<SourceRef>` 用の AST シンボル / 行範囲コード取得 |
| `GET /api/source/exports` | `<SourceRef mode="exports">` 用の AST 公開シンボル（class / interface / type / function 等）自動抽出 (`?file=src/...`) |
| `GET /api/code/tree` | Code Explorer 用：`projectRoot` 配下のソースファイルツリーと各ファイルの紐づき `<Spec>` / `<SourceRef>` / `<TermDef>` 件数サマリ（`node_modules`・`.git`・`dist`・`docs/`・隠しディレクトリ除外） |
| `GET /api/code/file` | Code Explorer 用：POSIX 相対パス (`?path=src/...`) の読み取り専用ソース全文・言語・総行数・公開シンボル (`exportedSymbols`)・紐づき `<Spec>` / ドキュメント / `<TermDef>` 逆リンク一覧（`projectRoot` 外は `403`、未存在は `404`、バイナリ・サイズ上限超過は `400`） |
| `GET /api/icons/manifest` | Material Icon Theme のファイル・フォルダ名／拡張子マッピング（ライトテーマ上書き込み）を返す |
| `GET /api/icons/:name` | Material Icon Theme の SVG アイコン（allowlist 登録済みアイコン ID のみ配信・長期キャッシュ付き） |
| `GET /api/media/*path` | `docs/` 配下のローカルメディア（画像・動画・音声）を安全配信（`docs/` 外・symlink 脱出・未許可拡張子は `403`、`X-Content-Type-Options: nosniff`、SVG には `Content-Security-Policy: sandbox`、動画・音声シーク用に HTTP `Range` / `206 Partial Content` 対応） |
| `GET /api/bundle` | 複数ドキュメントバンドル解決 (`?scope=all\|dir:...\|goal:...` または `?ids=...`) |
| `POST /api/export/pdf` | 単一文書の描画済み HTML から PDF 生成 |
| `POST /api/export/bundle-pdf` | ローカル `/bundle` URL を `Bun.WebView` で開いて複数文書 PDF 生成 |

## 主要エンドポイントの入出力スキーマ契約

- **Origin / CORS ガード**: `Origin` ヘッダがあるリクエストは `http://localhost:*`・`http://127.0.0.1:*`・`http://[::1]:*` のみ許可し、それ以外の外部 Origin は `/api/*` と `/mcp` の両方で読み書きとも `403` で拒否する（CSRF / DNS rebinding 対策）。`Origin` が無いローカルクライアント（CLI・curl 等）は許可する。
- **PDF 出力の境界**: `POST /api/export/pdf` は受け取った HTML を `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; img-src data:; font-src data:` 付きで描画し、スクリプト実行と外部・ローカルネットワークアクセスを許可しない。`POST /api/export/bundle-pdf` は常に自サーバー自身の Origin の `/bundle`（完全一致）のみを開き、リクエストでベース URL を指定できない。
- **ソース取得の除外**: `.env` など環境変数ファイルは `/api/source` / `/api/code/file` の対象外（拡張子 allowlist に含めない）。
- **`GET /api/blocks`**:
  - レスポンス: `{ blocks: ReviewBlockSummary[], counts: { approved, unreviewed, stale, suspect, changed } }`
  - 各要素は `id`, `kind`, `docId`, `docTitle`, `docPath`, `docDir`, `docFormat`, `rawBody`, `stability`, `review`, `suspect`, `suspectSources`, `changed`（作業ツリー／ブランチ差分で変更されたブロックか）, `approvedAt?`, `approvedBy?`, `approvedNote?`, `realization?` を返す。
- **`POST /api/blocks/:id/approve`**:
  - リクエスト JSON: `{ author?: string, note?: string }`（省略可）
  - レスポンス `200`: `{ block: SemanticBlock }`（未存在ブロックは `404`）
- **`POST /api/blocks/approve-batch`**:
  - リクエスト JSON: `{ ids: string[] (1件以上), author?: string, note?: string }`
  - 事前検証: `ids` に未存在ブロックが 1 件でも含まれる場合は書き込まず `404` を返す。
  - レスポンス `200`: `{ approvedIds: string[], count: number }`
- **`GET /api/blocks/:id/diff`**:
  - レスポンス `200`: `baseSource` を判別子とする判別共用体 `{ blockId, baseSource: "git", baseCommit, changed, lines }` / `{ blockId, baseSource: "cache", baseCommit?, changed, lines }` / `{ blockId, baseSource: "none", baseCommit?, changed, lines: [] }`（`lines` は `{ type: "context" | "add" | "del", text }[]`）
- **`GET /api/search`**:
  - クエリ: `q?`, `type?`, `limit?`（既定 `30`・最大 `100`）, `semantic?: "true" | "false"`
  - レスポンス `200`: `{ query, results: SearchHit[], count, mode: "bm25" | "hybrid", modelId? }`
- **`GET /api/code/file`**:
  - クエリ: `path`（`projectRoot` 相対 POSIX パス）
  - レスポンス `200`: `{ path, language, totalLines, content, exportedSymbols: ExportedSymbolEntry[], specs, docs, terms, covered }`
  - エラー: ルート外／シンボリックリンク脱出は `403`、未存在は `404`、バイナリまたは 1 MiB 超は `400`。

## 共通エラー規約と副作用の範囲

- **エラーレスポンス形式**: エラー時は JSON `{ code?: string, error: string }` を返し、`error` は英語の診断メッセージ、`code` には `src/core/errors.ts` の `TaggedError` タグ（例: `BlockNotFoundError`, `SourceOutOfRootError`, `SourceFileNotFoundError`, `DocumentNotFoundError`）を格納する（Zod バリデーションや単純なルートエラーでは `code` 省略可）。用途別に以下の HTTP ステータスを用いる。
  - `400`: クエリ・JSON ボディの Zod バリデーション違反、不正なパラメータ
  - `403`: 許可されない Origin、または `projectRoot` 外参照・非ループバック URL などの境界違反
  - `404`: 指定されたドキュメント・ブロック・ソースファイル／シンボルが存在しない
  - `409`: 状態競合
  - `500` / `501`: サーバー内部エラー、または実行環境で未対応の PDF 出力機能
- **副作用の範囲**:
  - すべての `GET` エンドポイントは読み取り専用（副作用なし）。
  - 書き込み系エンドポイント（`POST /api/blocks/:id/approve`・`POST /api/blocks/approve-batch`・`DELETE /api/blocks/:id/approve`）の副作用は **`docs/guard/reviews.json`（および `.documi/cache/`）の更新と SSE `reload` 配信に限定** され、MDX 本文は一切変更しない。
